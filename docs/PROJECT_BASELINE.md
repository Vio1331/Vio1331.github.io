## 4. 内容所有权与占位规则

### 受保护的真实内容

以下内容默认是用户内容，不得改写、删减或替换：

- `_journal/**` 中的文章正文
- `index.html` 中用户已经修改的首页文字
- `about.md`
- `_includes/footer.html`

真实文章中的图片引用即使失效，也不能擅自用占位图替换；应单独报告问题，等待用户提供或确认图片。

### 占位内容

当前 `_photography/**` 中标题以“摄影集示例”开头的条目属于模板占位内容。

占位文字只允许使用：

- 标题：`摄影集示例 01`
- 说明：`这是一段摄影集的示例文字。`
- 正文：`这是一段摄影集正文的示例文字。`
- 图注：`这是一段图片说明示例文字。`
- 地点：`示例地点`
- 设备：`示例设备`

禁止为占位内容虚构人物、经历、城市观察、情绪或文学化叙述。

唯一的网页占位图片为：

`/assets/images/window-light.webp`

内容描述：眼镜放在桌面上。所有示例封面和示例摄影集统一引用此文件，不生成新的替代图片。

## 5. 页面结构

| URL/类型 | 作用 | 不得混淆为 |
|---|---|---|
| `/` | 首页入口 | 文章列表页 |
| `/journal/` | 文章卡片列表 | 文章详情 |
| `/journal/:title/` | 单篇文章详情 | 摄影详情 |
| `/photography/` | 刊物封面网格形式的摄影集列表 | 精选照片墙 |
| `/photography/:name/` | 单个摄影集详情 | 文章卡片 |

有摄影集后，首页不再新增“精选照片”区域。

## 6. 局部修改协议

用户要求“只改某处”时：

1. 先记录目标文件和目标选择器。
2. 保存修改前的提交号与文件 SHA。
3. 只修改目标范围。
4. 对比修改前后差异，确认没有额外文件或额外选择器变化。
5. 若结果不满意，直接恢复该范围的旧代码，不重新设计其他部分。
